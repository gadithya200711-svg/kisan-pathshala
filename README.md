# 🌾 Kisan Pathshala - Kisan Alert

**Build with AI Hackathon 2025 - Track 4: Kisan Alert**

### Problem:
Small farmers lack real-time crop disease alerts in Telugu/Hindi voice

### Solution:
AI-powered app using Gemini Vision + Google Cloud TTS + SMS Alerts
- Farmer uploads crop photo
- Gemini AI detects disease (90% accuracy)
- Telugu/Hindi voice advisory
- SMS alerts to nearby farmers

### Tech Stack:
- Gemini 1.5 Flash (Vision)
- Google Cloud Text-to-Speech
- Streamlit / HTML
- Python

### Impact: 80% farmers in India are smallholders, need local language help
